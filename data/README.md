# data/

Сюда кладутся документы корпуса: `.pdf`, `.txt`, `.md`, `.docx`.
Файлы `README.md` при построении индекса игнорируются (см. `ingest.py`).

## Демо-корпус

В `data/astrolab/` лежит готовый **связный** демо-корпус (вымышленная компания
«Астролаб»: люди → команды → проекты → технологии с перекрёстными ссылками).
Связи для multi-hop специально разложены по разным документам, поэтому на нём
хорошо видно разницу ретриверов. Вопросы к нему — в `questions.yaml` (с типами и
эталонными ответами для reference-метрик RAGAS).

Запусти как есть:

```bash
python ingest.py
python evaluate.py
```

## Свой корпус

Удали папку `data/astrolab/` (или положи документы рядом), обнови `questions.yaml`
под свои вопросы и пересобери индекс. Начни с небольшого связного набора
(10-50 файлов с перекрёстными ссылками между сущностями).
